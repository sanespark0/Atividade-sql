# Atividade SQL — Plataforma de Cursos

Este repositório contém a resolução da lista de exercícios práticos de SQL Server, focada nos conceitos avançados de manipulação e automação de banco de dados.

## Conteúdos Abordados
A atividade foi dividida em 5 partes principais:
- **Transações (TCL):** Controle de alterações com `COMMIT` e `ROLLBACK`.
- **Views:** Criação de visões (`vw_Alunos`, `vw_MatriculasAlunos`, `vw_CursosCaros`) para facilitar consultas.
- **Stored Procedures:** Criação de procedimentos armazenados com parâmetros para listar e filtrar dados.
- **Functions:** Criação de funções escalares (ex: acréscimo de porcentagem em valores).
- **Triggers:** Automação de ações (envio de mensagem na inserção e bloqueio de valores negativos).

## Tecnologias Utilizadas
- **SQL Server** (Banco de dados)
- **T-SQL** (Linguagem de consulta)
- **VS Code** (Editor de código)
- **Git e GitHub** (Controle de versão)

##  Estrutura do Repositório
- `atividade_avancado.sql`: Arquivo contendo todo o script SQL com a resolução dos exercícios.

## Como executar
1. Clone ou baixe este repositório.
2. Abra o arquivo `atividade_avancado.sql` no SQL Server Management Studio (SSMS) ou no VS Code (com a extensão mssql).
3. Certifique-se de ter o banco `PlataformaCursos` criado e populado.
4. Execute as consultas de acordo com o enunciado.
